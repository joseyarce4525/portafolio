# Publicación y entrega

## 1. Revisa los datos
Confirma el nombre completo de la institución, tu grado y la finalización prevista en 2026. Revisa que puedas explicar cada aporte y cada tecnología. Cambia el nivel si alguno no corresponde.

## 2. Publica en GitHub Pages
1. Inicia sesión en https://github.com con tu cuenta y comprueba que tienes acceso a su correo. No compartas tu contraseña.
2. Crea un repositorio llamado portafolio-programacion-juan-jose-yarce. Hazlo público si puedes compartir este contenido.
3. Usa Add file > Upload files y sube los archivos que están dentro de esta carpeta. index.html debe quedar en la raíz, no dentro de otra carpeta. Guarda los cambios.
4. En Settings > Pages, selecciona Deploy from a branch; elige main y /(root), y guarda.
5. Espera a que GitHub indique que el sitio está publicado. Abre la URL que aparece allí y comprueba el portafolio y su hoja de vida.

Fuente oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 3. Completa el vínculo de la hoja de vida
El enlace actual index.html funciona al abrir la hoja de vida junto al portafolio y al publicarlos en la misma carpeta. Para compartir la hoja de vida por separado o como PDF, reemplaza href="index.html" en hoja-de-vida.html por la URL pública completa y comprobada. Añade esa URL también como texto visible debajo del enlace. Todavía no se incluye una URL pública porque no se conoce el usuario de GitHub.

Abre la hoja de vida y pulsa Imprimir / Guardar como PDF. Selecciona A4, escala 100 % y desactiva los encabezados y pies del navegador. Confirma que la vista previa ocupe una página y que el enlace del PDF funcione antes de entregarlo.

## 4. Añade las evidencias reales
Si tienes capturas, crea img/ y usa nombres como mundo-ciencia.png. Adjunta solamente imágenes o código que puedas compartir. Los proyectos PHP y MySQL requieren un servidor compatible; GitHub Pages publica este portafolio estático, pero no ejecuta esos proyectos de servidor. No publiques datos reales de empleados, contraseñas ni credenciales de bases de datos.
